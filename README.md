# Hollywood Film Analytics

## Movie Performance, Ratings & Profitability

An interactive Tableau dashboard designed to explore movie performance through ratings, worldwide gross, and profitability.

The project focuses on transforming movie data into clear visual insights that can support comparative analysis and data-driven decision making.

---

## 📊 Dashboard

The dashboard provides an overview of Hollywood movie performance through multiple visualizations.

### Main visualizations

- Top 10 highest-rated movies by genre
- Movie profitability analysis
- Worldwide gross comparison
- Movie performance distribution

### Key metrics analyzed

- General movie rating
- Worldwide gross
- Profitability
- Movie genre
- Individual movie performance

---

## 🎯 Project Objective

The objective of this project is to analyze movie performance using interactive data visualizations and identify patterns across movie ratings, profitability, and worldwide gross.

The dashboard was designed to make the information easier to explore and compare through visual analysis.

---

## 📈 Key Questions

This analysis explores questions such as:

1. Which movies have the highest ratings within each genre?
2. Which movies generate the highest worldwide gross?
3. Do highly rated movies necessarily have higher profitability?
4. How does movie performance vary across different films?
5. What patterns can be identified between ratings and financial performance?

---

## 🔎 Insights

Some of the main observations explored through the dashboard include:

- Movie ratings and financial performance do not necessarily move together.
- Some movies generate significant worldwide gross despite having different rating levels.
- Profitability varies considerably between movies.
- Comparing multiple dimensions provides a more complete view of movie performance than analyzing a single metric.
